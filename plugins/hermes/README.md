# Hermes distribution plan

No installable plugin yet. This directory will contain a native plugin manifest, registration, generated schemas/client, repository authoring skill and optional Designer profile. Use the shared Node service; preserve the user's selected Hermes home, identity and model/provider.

Acceptance requires dry-run, managed ownership hashes, update rollback, conflict-aware uninstall, doctor and API compatibility negotiation. See ../../docs/agent-integration.md. Do not ship a fake manifest that appears installable before these tools exist.
