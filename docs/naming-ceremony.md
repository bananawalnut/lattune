# Naming ceremony — open

The user rejected Lattune and asked for light materializing into form, initially Venusian and then more Saturnian. They clarified that this is a framework/instrument, not an agent, and suggested naming it after an object or artifact. Luci was an appealing sound, but did not imply enough creation/materialization on its own. Armillary and Orrery were proposed and rejected. No replacement name is accepted.

Current shortlist, offered as creative directions rather than availability claims:

| Name | Intended association |
|---|---|
| Lightloom | Weaving light and data into form |
| Formglass | Geometry, perspective and optical transformation |
| Chromalith | Color made solid |
| Lumenstone | Light given weight and substance |
| Reticle | Precision, alignment and cells finding their place |
| Heliostat | Controlled light shaped through geometry |
| Crucible | A vessel where inputs become something new |
| Phial | A small crafted vessel capable of holding light |
| Scryglass | An instrument making hidden structure visible |
| Prismarium | An imagined chamber for composing light and form |

The repository retains its temporary Lattune name and the private-alpha `@lattune/runtime` identifier until the user chooses. The names above have not been cleared or reserved. Product-name choice and package ownership are separate steps. No final rename or npm publication should be inferred from a preference question.
